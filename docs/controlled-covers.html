受控封面与本地保存

封面模板第 2 版从人物卡中先提取明确标注的姓名、外貌、服饰和可见饰物，再把这些片段与所选固定风格交给文字模型一次融合，形成视觉计划并顺序生成 1、2 或 4 张候选。故事创意字段须为空；文字与图片模型不接收大纲或整张人物卡。每张完成后保存，后续失败不删除已有图片；不会自动重复调用模型。

风格来源与选择

用户选择五种预设全部启用。风格定义及模型指令在后端维护，浏览器仅接收风格名称、流程阶段和图片结果，不显示或接受改写内部提示词。

以下五项是依据 GitHub 提示框架与示例改编的本项目预设，不是上游仓库已有的五条原样提示词。2026-10-09 核对的 OpenAI 示例包含 anime、watercolor、digital-art 等照片转换风格；ByteDance 和 Replicate 提供通用结构与描述原则。项目保留用户选择的五种方向，独立编写小说封面措辞，不复制技能全文，也未安装或执行仓库技能。

人物外观提取

支持冒号标签（中英文冒号）、列表及粗体标签，例如 - **外貌特征**：黑色短发，灰色眼睛。只保留姓名、名字、外貌特征、外貌、外观、服饰、服装、衣着、配饰、饰物、饰品和可见饰物字段；仅本字段后更深缩进的续行被保留，遇新标签、标题、空行或退回缩进便停止。身份、性格、经历、关系、能力、隐藏秘密及未标注自由散文不进入模型请求。

未找到任何明确可见外观时返回 cover_missing_appearance，不调用文字或图片模型；需作者补充外观标签。人物卡最多 12000 字，筛选后供提示词使用的片段最多 2400 字（按 JSON 引号转义后的长度计），过长时要求精简。文字模型仅调用一次融合外观与风格；所有视觉计划验证通过后才开始第一张图，图片请求再次附加原外观事实约束，不补缺失年龄、性别、人种、衣着或饰物。

字段筛选与计划结构校验不能证明自然语言或图片绝无语义偏移：若作者把经历写进外貌字段，它仍可能被视为字段内容。请保持每个字段只写可见特征，并对最终图片中的人物外观进行比较确认。

提示词边界

内部描述不进入前端包、接口结果、新封面版本或备份；旧封面 prompt 字符串在数据库升级和备份导入时去除，图片字节保留。公开旧 raw prompt 生成接口已关闭。

用户选择保留 Custom。自定义网关运营者可以接触模型请求，本功能不能对其保密，也不保证任何恶意输入都无法滥用。固定流程和输入校验用于约束本应用的入口，文字模型和生图服务的内容审核继续生效。

返回图片去除描述性元数据、ICC 和 EXIF。压缩像素不重编码，但嵌入色彩管理、EXIF 方向可能丢失；像素里的文字不属于元数据，不能由此清除。

保存位置

在支持原生目录 API 和安全锁的桌面浏览器，用户可选择文件夹，项目与模型配置自动同步为 braipen-workspace.json。IndexedDB 继续作为工作副本。完成文件 close 才标记同步成功；跨标签页共享锁保护快照和绑定变更。

浏览器通常只提供授权目录名称，网站不能写入任意未授权绝对路径。未知同名文件拒绝覆盖；换目录或停止同步不会删除原备份。手机与不支持目录 API 的浏览器使用下载备份和文件恢复。

Key 默认只在标签页内存使用，选择加密记住后在本地保险库保存。Key、加密保险库、口令和目录句柄不进入同步文件。恢复副本后连接重新编号并禁用，默认连接需重新选择，Key需填写或解锁。

服务器

项目与凭据不在服务器持久保存，模型计算只在请求内存中处理。公网模式默认关闭旧文件服务入口；模板代码属于应用配置，不是用户创作资料。部署还需关闭请求日志及磁盘缓冲，清理经用户批准的历史测试资料和日志。
