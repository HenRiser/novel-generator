受控封面与本地保存

图片生成先读取作者保存的白话设定和人物卡，经文字模型整理，再顺序生成 1、2 或 4 张候选。每张完成后保存，后续失败不删除已有图片；不会自动重复调用模型。

风格来源与选择

用户选择五种预设全部启用。风格定义及模型指令在后端维护，浏览器仅接收风格名称、流程阶段和图片结果，不显示或接受改写内部提示词。

预设视觉方向
电影写实真实人物和材质、戏剧性光影、克制色彩。
国风水墨笔触、墨色层次、纸感和留白。
轻小说插画清晰线条、人物主视觉和协调配色。
幻想写实幻想场景、可信材质、空间和光线。
极简象征核心意象、有限色彩和简洁关系。

本项目自行编写模板，参考以下资料的结构与风格描述方式，未安装或执行仓库技能：

  • ByteDance Seedream 官方技能（Apache-2.0）：主体、艺术风格、光影与构图。
  • Replicate 图像提示指南（Apache-2.0）：自然语言表达可画出的特征与空间关系。
  • OpenAI 官方风格示例（MIT）：用媒介、线条、材质和色彩描述固定风格。

提示词边界

内部描述不进入前端包、接口结果、新封面版本或备份；旧封面 prompt 字符串在数据库升级和备份导入时去除，图片字节保留。公开旧 raw prompt 生成接口已关闭。

用户选择保留 Custom。自定义网关运营者可以接触模型请求，本功能不能对其保密，也不保证任何恶意输入都无法滥用。固定流程和输入校验用于约束本应用的入口，文字模型和生图服务的内容审核继续生效。

返回图片去除描述性元数据、ICC 和 EXIF。压缩像素不重编码，但嵌入色彩管理、EXIF 方向可能丢失；像素里的文字不属于元数据，不能由此清除。

保存位置

在支持原生目录 API 和安全锁的桌面浏览器，用户可选择文件夹，项目与模型配置自动同步为 braipen-workspace.json。IndexedDB 继续作为工作副本。完成文件 close 才标记同步成功；跨标签页共享锁保护快照和绑定变更。

浏览器通常只提供授权目录名称，网站不能写入任意未授权绝对路径。未知同名文件拒绝覆盖；换目录或停止同步不会删除原备份。手机与不支持目录 API 的浏览器使用下载备份和文件恢复。

Key 默认只在标签页内存使用，选择加密记住后在本地保险库保存。Key、加密保险库、口令和目录句柄不进入同步文件。恢复副本后连接重新编号并禁用，默认连接需重新选择，Key需填写或解锁。

服务器

项目与凭据不在服务器持久保存，模型计算只在请求内存中处理。公网模式默认关闭旧文件服务入口；模板代码属于应用配置，不是用户创作资料。部署还需关闭请求日志及磁盘缓冲，清理经用户批准的历史测试资料和日志。
